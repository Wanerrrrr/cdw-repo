# Open Streets Community Poll

A standalone five-question Firebase poll for Assignment 7.

## Files
- `index.html` — poll page
- `style.css` — page styling
- `poll-app.js` — poll interaction and Firebase logic
- `firebase-config.js` — paste your Firebase web configuration here
- `firebase-rules.json` — Realtime Database rules for the assignment

Open `index.html` to preview the page. Add your Firebase configuration before publishing.
