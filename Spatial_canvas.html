Spatial Canvases
p5.js + three.js Experiments
Student
Waner Li

Project Summary

This project explores graphics as a computational design language. Through two p5.js sketches and two three.js experiments, I investigate how simple code-based systems can create atmosphere, rhythm, optical effects, and screen-based spatial experiences. Instead of treating code only as a tool for technical production, these studies use code as a material for visual choreography.

2D Spacial Canvas 1

This study is based on a visual illusion made from a checkerboard grid and repeated cross shapes. By controlling the color pattern through diagonal logic, the sketch produces a vibrating optical field. The project explores how small changes in repetition, contrast, and alignment can affect visual perception.

2D Spacial Canvas 2

This p5.js sketch uses layered noise values to generate a flowing field of circular dots. The dots change size and color based on brightness values, creating a motion graphic that feels like liquid, weather, or an electronic screen. The study focuses on how computational randomness can become a controlled visual rhythm.

3D Spacial Canvas 1

This three.js experiment uses three identical rectangular prisms to construct a spatial cross form. The prisms are aligned along the X, Y, and Z axes and share the same center point, producing a compact geometric structure from very simple primitive shapes.

3D Spacial Canvas 2

This three.js composition explores material through a set of floating frosted-glass cubes. Instead of using solid flat colors, the cubes are rendered with translucent blue-purple materials, rounded edges, soft reflections, and subtle surface noise. These material choices make the objects feel less like basic primitives and more like luminous glass blocks suspended in a dark digital space.
