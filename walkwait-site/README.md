# Did the Button Work? — Website First Draft

A responsive single-page website prototype for the Summer Colloquium interim submission.

## Files

- `index.html` — all website sections and the interactive crossing prototype
- `style.css` — visual system, layout, responsive behavior, and mockups
- `script.js` — navigation and crossing-scenario interaction

## Open locally

Double-click `index.html`, or run a local server inside this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Upload the three website files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the files and the `/root` folder.
5. Save and wait for the Pages link to appear.
