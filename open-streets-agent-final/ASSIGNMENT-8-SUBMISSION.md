## Description

I created an Open Streets Planning Agent that helps users turn a neighborhood street idea into a cautious first-draft proposal. The agent focuses on possible uses, operating schedules, accessible pickup and delivery access, emergency access, staffing, maintenance, and community outreach. Firebase connects the web interface to the backend service, while the OpenAI API generates responses based on the user’s scenario.

## How I might use this approach

This approach could become an early participatory-planning tool within a larger NYC Open Streets project. It could help residents identify priorities and trade-offs before a formal proposal is developed. The generated suggestions would remain preliminary and should be checked against NYC DOT guidance and local stakeholder input.
