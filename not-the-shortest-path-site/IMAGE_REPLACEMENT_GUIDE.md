# Image Replacement Guide

Search `index.html` for the comments beginning with `Replace` to find the image galleries quickly.

Recommended image proportions:

- Historical lineage: approximately 1.22:1
- Community of practice: approximately 1.6:1
- Computational experiments: approximately 1.9:1
- Visual moodboard: flexible; the CSS crops images with `object-fit: cover`
- Exhibition components: approximately 1.45:1

To preserve the current layout, crop your replacement images before uploading or allow the website to crop them automatically.

All current placeholders are original SVG illustrations and can be edited in Figma, Illustrator, or a code editor.
