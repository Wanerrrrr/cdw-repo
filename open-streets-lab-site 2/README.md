# Open Streets Lab — First Draft

A responsive research-foundations website for the NYC Open Streets capstone direction.

## Current structure

The website uses a complete left-side section navigation on desktop and a scrollable menu on smaller screens. The presentation is ordered as:

1. Research foundations and context
2. Methods and prior experiments
3. Rhetorical argument, capstone outline, challenges, and exhibition proposals
4. Proposed output at the end: the platform and its three connected tools

The three prototype tools are:

- Open Street Equity Explorer
- Open Street Scenario Builder
- Open Street Application Assistant

## Files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` directly, or serve the folder locally with a simple HTTP server. The prototype scores and candidate locations are illustrative and are labeled as such in the interface.
